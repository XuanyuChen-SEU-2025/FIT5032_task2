# xchen-library

FIT5032 Assessed Lab 2 Vue 3 project.

## Project Setup

```sh
npm install
```

## Run Development Server

```sh
npm run dev
```

## Build

```sh
npm run build
```

## Lab Work Completed

- JSON data import from `src/assets/json/authors.json` and `src/assets/json/bookstores.json`
- Vue 3 Composition API with `script setup`
- Computed properties, `v-for`, `v-if`, `v-else`
- JSON arrays, objects, nested arrays, and nested objects display
- Attribute binding, class binding, and style binding
- George Orwell dynamic highlighting
